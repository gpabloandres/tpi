📦 ¿Qué se Entrega?

📄 Informe Escrito

Un documento completo (máx. 50 pág.) que incluye el Plan de Negocios y toda la Documentación Técnica del proyecto.

Ver Estructura del Informe ▼
  • Sección 1: Información General
  • Sección 2: Proyecto y Fundamentación
  • Sección 3: Desarrollo Técnico
  • Sección 4: Plan de Negocios
  • Sección 5: Gestión del Proyecto

🎤 Presentación Oral y Demo

Una exposición de 15-20 min. (más preguntas) donde presentan su "pitch" y muestran el prototipo funcionando en vivo.

Claves de la Presentación ▼
  • Elevator Pitch atractivo
  • Demostración del prototipo
  • Explicación del modelo de negocio
  • Reflexión sobre aprendizajes
  • ¡Participación de todo el equipo!

📊 ¿Cómo se Evalúa?

La nota final es una ponderación de tu trabajo técnico, tu visión de negocio, tus habilidades blandas y la calidad de tu presentación.

50% - Conocimientos Técnicos
15% - Plan de Negocios y Viabilidad
20% - Habilidades Blandas y Equipo
15% - Presentación y Documentación

💻 Taller de Programación Web

Aquí crearán la interfaz con la que interactuará el usuario.

  • Arquitectura Cliente-Servidor: Definir cómo se comunican el frontend y el backend.
  • Frontend: Desarrollar la parte visual con HTML, CSS y JavaScript. Debe ser intuitiva y accesible.
  • Backend: Programar la lógica del servidor, la conexión a bases de datos y la creación de APIs para manejar la información.
  • Despliegue: Poner la aplicación en un entorno real para que sea accesible.
×

🎨 Laboratorio: Diseño de Software

Es el cerebro de su solución. Aquí se define la lógica y la estructura interna.

  • Metodología Ágil: Usar Scrum o Kanban para organizar el trabajo y adaptarse a los cambios.
  • Diseño Modular: Crear un software bien estructurado, con bajo acoplamiento y alta cohesión.
  • Diseño con Objetos: Utilizar diagramas de clases, objetos y secuencia si el proyecto lo requiere.
  • Testing: Realizar pruebas unitarias y de integración para asegurar que todo funcione correctamente.
×

🤖 Laboratorio: Sistemas Embebidos

El hardware que interactúa con el mundo real: captura datos, controla dispositivos, etc.

  • Hardware: Diseñar o seleccionar los componentes: microcontrolador, sensores, actuadores.
  • Arquitectura: Detallar cómo funciona el sistema embebido.
  • Firmware: Programar el software que corre dentro del microcontrolador.
  • Interfaces: Diseñar la comunicación con otros componentes (USB, I2C, etc.) y los circuitos de apoyo.
